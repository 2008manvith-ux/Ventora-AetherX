# Ventora — AetherX

Ventora is an AI-assisted concept prototype by Team AetherX exploring how inventors could test demand for product ideas and connect with early supporters, manufacturers, and promoters.

This repository contains a **front-end demonstration**, not a production service.

## What the prototype shows

- A landing page and sample product campaigns
- Customer, inventor, manufacturer, and influencer views
- Example campaign, preorder, interest, and quotation flows
- INR formatting and seeded sample data

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. The page loads Tailwind CSS from its CDN, so an internet connection is needed for the styling.

No build step or package installation is required.

## Prototype limitations

- Campaigns and interactions are simulated in the browser.
- Demo data and changes are stored in that browser's local storage.
- There is no backend, account authentication, real payment processing, or actual order/manufacturing workflow.
- Names, campaign figures, and example activity are sample content.

Please treat all funding and preorder amounts as demonstrations only; no money is collected.
